AZCHESS integrated package

Included:
- Phase 1 chess UI and SVG pieces
- PeerJS/WebRTC online multiplayer
- Room creation/joining
- Online move synchronization
- Online draw/resign/rematch controls
- Connection/rejoin handling
- Online chat

GitHub Pages:
- index.html is at repository root
- JavaScript modules are under js/
- PeerJS 1.5.4 and chess.js 0.10.3 are loaded from public CDNs

This package has been statically checked for JavaScript syntax and wiring. A live two-browser WebRTC test still requires opening the deployed site in two browser sessions.
